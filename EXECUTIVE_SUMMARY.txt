   — Fresh production database cannot be initialized
   — Risk: BLOCKER for deployment

3. NO CSRF PROTECTION ON API ROUTES
   — CSRF utility exists but is not applied anywhere
   — Risk: MEDIUM — OWASP Top 10 (A1)

4. IN-MEMORY RATE LIMITING
   — Resets on server restart
   — Not shared across instances
   — Risk: MEDIUM for multi-instance deployment

5. ALL PAGES ARE "use client"
   — No React Server Components
   — All JavaScript sent to browser
   — Risk: MEDIUM — larger bundles, slower initial load

6. PASSWORD RESET TOKENS STORED IN PLAINTEXT
   — DB compromise exposes reset tokens
   — Risk: LOW-MEDIUM — tokens have 1-hour expiry

7. NO CACHING LAYER
   — Every dashboard load re-fetches all data
   — Risk: LOW-MEDIUM — acceptable for single user, not for scale
